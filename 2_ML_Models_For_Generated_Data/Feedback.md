### Marking method:

*The scaling of scores was done so that a mark of 0 corresponded to predictions that were no better than random, and 100 corresponded to the best possible accuracy. 
A mark close to 0 could occur if a model's predictions were only very slightly better than random.*

**NB:** *bigdata* had a low score due to not using a *tree* method which would've been the best type of ML method to use and so the results were only slightly better than random.
